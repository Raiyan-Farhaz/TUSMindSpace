# TUSMindSpace

TUSMindSpace is an Android application designed to support the mental wellbeing of TUS students.



**Planned Features:**



Mood tracking



Personal journaling



Guided meditation



Daily notifications



Wellbeing resources





**Technologies:**



Kotlin



Jetpack Compose



Android Studio



Navigation Compose



**Current Progress — Sprint 1:**



Android Studio project created.



Initial screen files created.



Basic navigation between screens planned for implementation.
